# TestGit

A small Git repo that test git knowledge:

## TASKS

1. Clone the repository.
2. Create a branch named `feature/fix-readme`.
3. Change one line in `README.md`, commit it, and push the branch.
4. Switch to `main`, change the same line, commit it, then merge their branch.
6. Resolve the resulting merge conflict sensibly.
7. Use `git log` and `git diff` to explain what changed.
8. Make one small change, then demonstrate how they would safely undo it after committing.
